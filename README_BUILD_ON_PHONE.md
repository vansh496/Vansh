# Shri Hit Chaurasi Ji - Android APK build

This is a Qt 6 / C++ / QML Android project.

## Build without a PC

1. Create a GitHub repository.
2. Upload all files/folders from this project to the repository root.
3. Open the **Actions** tab.
4. Select **Build Shri Chaurasi Pad Android APK**.
5. Tap **Run workflow**.
6. When it finishes successfully, open the workflow run and download the **ShriHitChaurasi-APK** artifact.

The workflow builds an ARM64 Android APK using Qt 6.8.3, Android API 35, and NDK 26.1.10909125.
